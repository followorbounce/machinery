# Heavy Machinery Encyclopedia

Static site cataloguing 20 record-setting heavy machines plus 10 engineering concepts, generated entirely by one Python build script — no hand-written page HTML.

## Structure
- `build.py` — the entire site generator (single ~172KB script). All page content, machine data, and templating live here; **edit `build.py` and re-run it, don't hand-edit generated HTML** in `machines/`, `concepts/`, or `quiz/`.
- `machines/<slug>/` — 20 generated machine pages (e.g. `liebherr-r9800`, `bagger-293`, `big-muskie-dragline`).
- `concepts/<slug>/` — 10 generated engineering-concept pages (torque, gear ratios, planetary gears, Pascal's Law, hydraulic cylinders, four-stroke diesel cycle, torque converters, final drives & differentials, bearings, mechanical advantage).
- `quiz/` — a 10-question personality quiz matched against the 20 machines' real specs, also build-generated.
- `data/` — source data the build script reads.
- `assets/` — shared CSS/JS/images used across generated pages.
- `index.html`, `sitemap.xml`, `llms.txt`, `robots.txt` — regenerated by `build.py`; don't hand-edit.

## Conventions
- Single source of truth is `build.py` + `data/` — treat generated HTML as build output, not source.
- Real machine photos come from Wikimedia Commons, **verified-license only** (see commit `d8388e9`) — don't add images without checking license status.
- Scale-comparison diagrams: human figure scales to the equipment, not the reverse (see commits around `b3073c5`/`ef52844`) — keep that convention if extending the diagram.
- Never use Russian in code/UI/docs unless the task explicitly calls for it.

## Share pictures (og:image)
Added 2026-10-28. Every public page has a 1200×630 share picture at `og/<canonical path>.jpg` (`og/index.jpg` for the front page) and the tags `og:image` (+ width, height, alt), `twitter:card` = `summary_large_image` and `twitter:image`. `build.py` writes the tags (`og_tags()` via `head_tmpl()`); the hand-written `quiz/index.html` carries them directly, placed after the page's other og:/twitter: tags. The pictures are drawn by `engine/og_cards.py` in the followorbounce.github.io repo (one card template, this site's own palette and type, `og/manifest.json` = a hash per card so unchanged cards are skipped). After adding or renaming a page, or changing a title or description, run `python3 engine/og_cards.py machinery` from that repo; it renders new cards, adds missing tags and deletes cards of pages that went away. `--check` lists pages without tags.
